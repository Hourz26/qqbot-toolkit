## 四、怎么恢复本地这套

```powershell
# 1. 恢复自动守护
Enable-ScheduledTask -TaskName 'SnowLuma-Guard'
Move-Item 'D:\Apps\snowluma\disabled-autostart\SnowLuma-Guard.lnk' "$env:APPDATA\Microsoft\Windows\Start Menu\Programs\Startup\"

# 2. 起服务
pm2 start snowluma
pm2 start astrbot
pm2 save

# 3. （可选）跑一次守护脚本，会重新挂载并纠正账号
powershell -NoProfile -ExecutionPolicy Bypass -File D:\Apps\snowluma\watchdog.ps1

# 4. 验证
pm2 list
netstat -ano | findstr "5099 6185 6199"
Invoke-WebRequest http://127.0.0.1:6185/ -UseBasicParsing
```

如果想顺手把坑 10 修掉：先把账号在 QQ 里换回来，再 `pm2 start snowluma`，最后跑 watchdog 让它挂到小号所在的客户端。

## 五、云端迁移时注意（摘要）

- SnowLuma 是**注入 QQNT 客户端**的网关，依赖 `QQ.exe` 进程 —— Linux 云服务器上没有它。
- 云端要的是 headless 网关（NapCat / Lagrange / LLOneBot），AstrBot 侧只需改 `ws_reverse_*` 地址和 token，其余不用动。
- 云服务器 IP 登录 QQ 容易触发异地风控，**只用小号试**，别拿主号。
- 同一个 QQ 号不能两处同时在线，切换前先停本地。
